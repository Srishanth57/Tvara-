## 🧠 What is Machine Learning (ML)?

> *Generated by Gemini 3 Flash Preview*

**ML** stands for **Machine Learning** — a branch of Artificial Intelligence (AI) that enables systems to **learn from data**, identify patterns, and make decisions with minimal human intervention.

Instead of a human writing specific code for every scenario, the computer **trains itself** using data to find the best way to complete a task.

---

### Traditional Programming vs. Machine Learning

| Approach | Formula | Example |
|---|---|---|
| **Traditional Programming** | Input + Rules → Output | "If email contains 'Winner', mark as Spam" |
| **Machine Learning** | Input + Output → Rules | Feed 10,000 labeled emails; the model learns spam patterns |

---

### The Three Main Types of Machine Learning

#### 1. 🎓 Supervised Learning *(Learning with a teacher)*
The model is trained on **labeled data** where answers are already known.
- **Example:** Showing thousands of photos labeled "Dog" or "Cat" until the model can identify them independently.

#### 2. 🔍 Unsupervised Learning *(Learning on its own)*
The model is given **unlabeled data** and finds hidden patterns or groupings.
- **Example:** A clothing brand's ML algorithm grouping customers into "High Spenders" and "Bargain Hunters" based on behavior.

#### 3. 🎮 Reinforcement Learning *(Trial and error)*
The model learns by **interacting with an environment**, receiving rewards for good actions and penalties for bad ones.
- **Example:** A computer learning to play a video game, or a robot learning to walk.

## 💻 LeetCode Solution — Linked List Cycle II

**Problem:** [142. Linked List Cycle II](https://leetcode.com/problems/linked-list-cycle-ii/)

Given the head of a linked list, return the **node where the cycle begins**. If there is no cycle, return `null`.

---

### 🧩 Approach — Floyd's Cycle Detection (Two Pointers)

This solution uses **Floyd's Tortoise and Hare algorithm** in two phases:

**Phase 1 — Detect the cycle:**
- Move `slow` one step at a time, `fast` two steps at a time.
- If they meet, a cycle exists.

**Phase 2 — Find the cycle start:**
- Reset `slow` to `head`, keep `fast` at the meeting point.
- Move both one step at a time — they will meet at the **cycle entry node**.

---

### 📝 C++ Solution

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(NULL) {}
 * };
 */
class Solution {
public:
    ListNode *detectCycle(ListNode *head) {
        ListNode* slow = head;
        ListNode* fast = head;

        // Phase 1: Detect cycle
        while (fast != slow) {
            slow = slow->next;
            fast = fast->next->next;
        }

        // Phase 2: Find cycle entry node
        slow = head;
        while (fast != slow) {
            slow = slow->next;
            fast = fast->next;
        }

        return slow;
    }
};
```

> ⚠️ **Note:** This solution assumes the linked list **contains a cycle**. If the list may have no cycle, add a null-check guard before `fast->next->next` in Phase 1.
